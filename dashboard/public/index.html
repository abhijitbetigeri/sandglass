Capability control plane · AI Security Hackathon 2026

Run AI agents on edge devices as if they're already compromised.

An agent on an edge device inherits that device's full authority. Prompt-inject it and the attacker has the signing keys, the network, and the wire to the hardware — and out there, there is no cloud to call for help. Sandglass gives the agent none of it. It runs in a Wasmer sandbox with no network and no keys, so it cannot act, only ask.

Demo — 2:25. Every terminal frame and console view is real output from the running system.

How it works

Three boundaries, each stopping a different attack.
BOUNDARY 1
Wasmer sandbox

Stops a hijacked application. No network, no keys, no effector. The agent's only way out is to print a JSON request on stdout.

BOUNDARY 2
3-of-5 quorum

Stops a captured device. Peers re-check each request against their own policy and their own local facts before signing. One owned node can't act alone.

BOUNDARY 3
Host runtime

The only code that touches the real world. It holds the signing key and the effector handle, outside the sandbox, and acts only after 1 and 2 both pass.
